> **Update (migration 0600 and API hardening).** Rows describing database controls were written against migrations 0100-0500. Migration `20261010000600_hardening.sql` and the API changes after the independent review ([`../security/review-2026-10-10.md`](../security/review-2026-10-10.md)) strengthen several of them (actor model, audit scope, offers, payments, history, consent, logging). ## Read this first

- **Research limitation.** No primary regulatory text could be opened during research: rbi.org.in and the other primary sites were unreachable (WebFetch DNS failure; proxy blocked HTTPS) and the shared web-search budget ran out. The requirements below rest on search snippets and secondary sources (law firms, press, lender-published notices). Every paragraph reference must be verified against the primary RBI, UIDAI, MeitY, NPCI, CERT-In or store text before it is relied on in a contract, policy, disclosure or launch decision. **This is a release gate.**
- **No compliance claim.** This matrix says which control exists or is planned, what evidence it should produce and what is still to verify. It does not say Udofin is compliant.
- **Baseline checked.** Every "Implemented" or "Partial" entry was checked against the code on 10 Oct 2026: the five migrations in `supabase/migrations/`, the three pgTAP files in `supabase/tests/`, and the other files named in the row. Where a control exists only as configuration with no automated test, the row says so.

## 2. How to read the matrix

- **ID:** domain prefix and number.
- **Source:** instrument and paragraph where a research note states it; otherwise "para to verify". Square brackets give the research rows merged into this row: RDL = `docs/research/2026-10-10/rbi-digital-lending.md`, KYB = `docs/research/2026-10-10/kyc-aadhaar-bureau.md`, PSO = `docs/research/2026-10-10/privacy-security-outsourcing.md`, GAC = `docs/research/2026-10-10/grievance-adr-collections.md`, ASM = `docs/research/2026-10-10/app-store-mobile.md`, CUX = `docs/research/2026-10-10/competitors-ux.md`, PPY = `docs/research/2026-10-10/providers-payments.md`, INF = `docs/research/2026-10-10/infra-stack.md`, ECO = `docs/research/2026-10-10/ecosystem-sites.md`. "DL Directions 2025" means the RBI (Digital Lending) Directions of 8 May 2025; "CF Ch. III" means the digital-lending chapter of the Credit Facilities Directions 2025 for the lender's type.
- **Status:** research label (see 1.1). ‡ = other notes differ.
- **Responsible:** RE (the lender), Udofin, both, or provider (a vendor or sister product).
- **Code references:** M0100–M0500 = `supabase/migrations/20261010000100_foundation.sql`, `…0200_tenancy_and_access.sql`, `…0300_identity_consent_audit.sql`, `…0400_lending_core.sql`, `…0500_servicing_payments.sql`. T001–T003 = `supabase/tests/001_structure.test.sql`, `002_tenant_isolation.test.sql`, `003_lifecycle_and_integrity.test.sql`. Quoted text in a row is the exact pgTAP or unit-test description.

### Gaps found while checking the baseline

1. `lending.offers.tenure_days` and `lending.loan_requests.requested_tenure_days` are not checked against the platform tenure floor or the product version's bounds (APP-03).
2. `payments.payment_intents.settlement_account_ref` is free text; nothing in the database ties it to an account configured for that lender (MNY-02).
3. A payment intent can be marked `succeeded` by the system without a linked `signature_verified` provider event (MNY-02).
4. Applications can be created by the system without checking `consent.current_decisions` for that lender (MLD-01, DAT-01).
5. `lending.offers.kfs_document_id` is nullable, so an offer can exist without a KFS link until Phase 07 (MLD-02, DLC-03).
6. `private.current_actor()` treats every authenticated non-borrower as `lender`; protection against platform staff deciding rests on RLS and permissions, and the `system` path can approve or reject (DLC-08).
7. M0100 relies on `supabase/config.toml` to keep domain schemas out of PostgREST, but that file is not in the repository (DAT-13).
8. The mobile permission controls and OTA setting are configuration only; there is no CI workflow or merged-manifest check yet (DEV-01–05, APP-14).
9. Four permissions recommended by research are not in `blockedPermissions`: READ_MEDIA_VISUAL_USER_SELECTED, RECEIVE_WAP_PUSH, REQUEST_INSTALL_PACKAGES and `com.google.android.gms.permission.AD_ID` (DEV-04).

## 5. Maintaining this matrix

Change it in the same pull request as the regulatory register (`docs/regulatory/register.md`, section 4) whenever an instrument, a label, a control or a phase changes. A row moves to "Implemented" only when the control exists in code and, wherever possible, a test proves it; cite the file and test description. A status label changes only after counsel or the compliance owner has read the primary text and recorded it in the register's change log.
