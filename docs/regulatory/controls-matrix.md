## 2. How to read the matrix

### Gaps found while checking the baseline

1. `lending.offers.tenure_days` and `lending.loan_requests.requested_tenure_days` are not checked against the platform tenure floor or the product version's bounds (APP-03).
2. `payments.payment_intents.settlement_account_ref` is free text; nothing in the database ties it to an account configured for that lender (MNY-02).
3. A payment intent can be marked `succeeded` by the system without a linked `signature_verified` provider event (MNY-02).
4. Applications can be created by the system without checking `consent.current_decisions` for that lender (MLD-01, DAT-01).
5. `lending.offers.kfs_document_id` is nullable, so an offer can exist without a KFS link until Phase 07 (MLD-02, DLC-03).
6. `private.current_actor()` treats every authenticated non-borrower as `lender`; protection against platform staff deciding rests on RLS and permissions, and the `system` path can approve or reject (DLC-08).
7. M0100 relies on `supabase/config.toml` to keep domain schemas out of PostgREST, but that file is not in the repository (DAT-13).
8. The mobile permission controls and OTA setting are configuration only; there is no CI workflow or merged-manifest check yet (DEV-01–05, APP-14).
9. Four permissions recommended by research are not in `blockedPermissions`: READ_MEDIA_VISUAL_USER_SELECTED, RECEIVE_WAP_PUSH, REQUEST_INSTALL_PACKAGES and `com.google.android.gms.permission.AD_ID` (DEV-04).

## 5. Maintaining this matrix

Read "confirmed (primary text)" as "an analyst read the paragraph in the PDF on file and the extraction note records it"; it does not replace counsel review. Change it in the same pull request as the regulatory register (`docs/regulatory/register.md`, section 4) whenever an instrument, a label, a control or a phase changes. A row moves to "Implemented" only when the control exists in code and, wherever possible, a test proves it; cite the file and test description. A status label changes only after counsel or the compliance owner has read the primary text and recorded it in the register's change log.
