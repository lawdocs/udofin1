# Module specifications

One file per module, written and approved before implementation (see `CLAUDE.md` → workflow).
Name files `NN-module-name.md` after the roadmap phase. Each spec contains: business objective,
assumptions, scope and out-of-scope, user journeys, data model changes, API endpoints, permissions,
state transitions, failure handling, regulatory controls (IDs from `../regulatory/controls-matrix.md`),
acceptance criteria, test plan and open questions.

No module specs exist yet; Phase 02 is the first to need one.
