## Status definitions

| Status      | Meaning                                                                                                                      |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Not started | No code, schema or configuration for the module.                                                                             |
| Baseline    | Schema, skeleton or configuration exists and is covered by tests, but there is no API endpoint or user interface for it yet. |
| In progress | Being built in an open phase.                                                                                                |
| Done        | Built, tested, reviewed, merged and accepted by you for its phase.                                                           |

No module is **Done** yet. Phase 01 itself is complete and awaiting your approval.
